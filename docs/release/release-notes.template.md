QA 포트폴리오용 Android 데모 앱의 시험판입니다.

## 받을 파일

| 파일 | 누구 |
| --- | --- |
| `rwa-mobile-{{version}}-arm64.apk` | **대부분의 Android 폰** (Android 7.0 이상) |
| `rwa-mobile-{{version}}-x86_64.apk` | PC의 Android 에뮬레이터 |

## 설치

1. 폰에서 APK를 받아 엽니다.
2. "출처를 알 수 없는 앱" 설치를 허용합니다.
3. 설치한 뒤 회원가입하고 로그인합니다.

인터넷이 필요합니다. 앱이 요청하는 권한은 인터넷 하나입니다.

## 알아 두실 것

- **실제 개인 정보와 평소 쓰는 비밀번호를 넣지 마세요.** 지어낸 정보만 넣어 주세요. 다른 방문자가 볼 수 있습니다.
- 은행 계좌와 돈은 모두 가짜입니다.
- 서버가 다시 시작되면 로그인이 풀릴 수 있습니다.
- 시험판이라 확인하지 못한 기기가 많습니다.

## 확인용 값

- 버전: `{{version}}`, 커밋: `{{commit}}`
- 파일의 SHA-256은 `SHA256SUMS.txt`에 있습니다.
- 서명 인증서의 SHA-256: `{{certificate}}`
